## 2. 게임 설명
    Number Pet은 여러 나라를 모험하며 숫자 문제를 풀고 쿠키를 얻어 나만의 애완 동물을 육성하는 학습형 게임이다. 

    문제의 풀 때마다 쿠키가 지급되며, 펫은 쿠키를 먹고 성장해 나간다. 남은 쿠키로 애완 동물에게 간식이나 놀이도구를 사며 펫의 정서도 돌볼 수 있다.

    쿠키가 쌓이면서 레벨이 올라가고, 오른 레벨에 따라 펫은 성장하고 난이도가 높은 스테이지에 도전할 수 있다.  

    2.1. 게임방식
    * 화면 상단에서 문제가 적힌 문제 상자가 일정 속도로 내려온다. 
    * 플레이어가 문제를 풀기 위해 클릭(터치)하면 내려오던 상자가 잠시 멈춘다.
    * 이때 플레이어는 아래쪽에 생긴 숫자가 쓰인 보기 풍선 중 하나를 선택해 답을 고른다.
    * 정답을 맞추면 내려오는 문제 상자가 없어지면서 쿠키가 늘어난다.
    * 문제를 푸는 동안 다른 문제 상자들은 계속 천천히 내려온다.
    * 기본적으로 한 스테이지는 10개의 문제가 나온다.  
    * 총 10문제 푸는 데 시간 제한은 없다.
    * 오답 및 놓친 문제도 한 스테이지의 문제수 10개에 포함된다.
    * 모든 문제(10문제)를 풀면 스테이지를 종료한다.
    * 제한 시간은 없지만 상단에 모래시계의 모래가 줄어드는 타이머는 있다.
    * 모래 시계의 모래가 소진되어도 스테이지를 종료하지 않는다. 
    * 스테이지가 종료되었을 때 모래시계의 남은 모래 비율만큼 쿠키를 추가 지급한다.
        * 25% 이상이 남으면 1개 추가, 75% 이상이 남으면 2개 추가

    2.2. 레벨 구성
    * 더하기/빼기 나라
        * 레벨1: 올림/내림이 없는 덧셈, 뺄셈
        * 레벨2: 올림/내림이 있는 한 자리수 덧셈, 뺄셈
        * 레벨3: 올림/내림이 있는 두 자리수 덧셈, 뺄셈
        * 레벨4: 4+X=13, 10-X=7 과 같은 방정식에서 X를 구하는 문제 
        * 레벨5: 두 자리수 덧셈과 뺄셈이 섞여 있는 혼합 연산(예: 53-17+22=)
    * 곱하기/나누기 나라는 추후 확장
    
    2.3. 정답입력 방식
    * 초급모드
        * 정답 후보 풍선 3개
        * 문제 상자 낙하 속도 느림
        * 정답 선택 시 기본 쿠키 지급 (정답 1개당 쿠키 1개)
    * 중급모드
        * 정답 후보 풍선 5개
        * 문제 상자 낙하 속도 조금 빠름
        * 펫이 2단계 성장을 하면 적용 
        * 정답과 유사한 숫자를 오답후보로 구성
    * 보너스 미션
        * 문제 상자를 클릭(터치)하면 키패드 입력으로 정답 입력
        * 정답시 추가 쿠키 지급
        * 필수 클리어 조건이 아닌 선택적 도전
        * 중급모드에서 한 스테이지를 클리어 하면 쿠키 2개를 써서 도전여부 결정
    
    2.4. 스테이지 진행방식
    * 한 스테이지는 총 10문제로 구성
    * 하루에 총 3스테이지를 할 수 있음.
    * 1문제 정답에 하나의 쿠키를 획득
    * 하루에 최대 3스테이지*10개 = 20 개 쿠키 획득 가능
    * 보너스 미션까지 하면 추가 쿠키 획득 가능
    * 하루 2 스테이지를 완료하면 획득한 쿠키를 먹고 조금씩 성장함.
    * 펫은 매일 5개의 쿠키를 먹음. 쿠키가 부족하면 펫이 성장 못함.
    * 연속 7개 이상 정답시 콤보 메시지 뜨면서 특수 아이템 지급 (아래 3종)
        * 모든 문제 상자를 5초간 멈춤 (이때 화면에 아이템 유효시간 표시)
        * 현재 화면에 있는 문제 상자의 낙하 속도를 느리게 
        * 5초간 더블 쿠키 (한 문제당 쿠키 2개 지급) (이때 화면에 아이템 유효시간 표시)


    2.5. 하루 제한
    * 하루에 총 3개의 밀가루 봉지 제공, 1봉지 = 1 스테이지 도전 가능
    * 매일 아침 7시에 밀가루 봉지 충전.
    * 밀가루 봉지 소진하면 내일 또 도전하세요. 라며 종료
    * 재접속 및 새로고침으로 충전되지 않아야 함.
    * 하루 접속을 안했다고 해서 더블로 지급되지 않음. 접속한 날만 밀가루 3봉지 충전
    
    2.6. 하루 종료 연출
    * 오늘 도전한 문제수와 정답률, 획득한 쿠키 정보 표시
    * 펫 성장상태 표시 (HP 수치)
    * 쿠키 5개 미만이면 HP 내려감. 이때 쿠키는 소진되지 않고 내일로 이어짐.
    * 쿠키 5개 이상 먹으면 보유쿠키 5개 소진되고 HP 1상승. 기뻐하는 표정

    2.7. 애완동물 
    * 강아지, 고양이 2종
    * 시작시 플레이어가 원하는 캐릭터 선정
    * 펫의 성장 상태로 HP 보유. 0부터 시작. 하루에 쿠키 5개 먹으면서 HP 1씩 상승.
    * 결국 넘버 펫 게임 레벨은 펫의 HP가 중요
    * 성장 상태는 영구적으로 유지

    2.8. 캐릭터 애니메이션
    * 기본 대기
    * 눈 깜빡이기
    * 몸 흔들기
    * 쿠키 먹기
    * 정답을 맞혔을 때 기뻐하기
    * 미션 클리어시 춤추기
    * 성장
    * 하루 3 스테이지 클리어 후 밀가루 소진시 잠들기

## 3. 화면 구성
    3.1. 메인 화면
    * 게임 제목 (Number Pet)
    * 현재 캐릭터 대기
    * 펫 성장상태 (HP 표시: HP는 매일 쿠키를 5개씩 먹으며)
    * 보유 쿠키
    * 남은 밀가루 (스테이지 도전 횟수)
    * 현재 수학 나라 (덧셈/뺄셈 나라, 곱셈 나라 등)
    * 스테이지 시작버튼

    3.2. 게임화면
    * 낙하하는 숫자 상자
    * 선택된 문제 표시
    * 문제 선택시 아래쪽 정답 후보 풍선 또는 키패드
    * 현재 캐릭터
    * 쿠키 획득량
    * 스테이지 진행상태
    * 아이템 사용 버튼
    * 모래 시계
    * 문제가 내려오는 화면 오른쪽으로 펫의 상태 (HP), 표정, 보유 쿠키수, 보유 아이템 표시


    3.3. 결과 화면
    * 해결한 문제 수
    * 정답 수
    * 획득 쿠키
    * 캐릭터 성장 결과
    * 다음 스테이지 또는 오늘의 종료
